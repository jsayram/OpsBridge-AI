## Decisions, teaching notes and approvals

**Teach-back.** A migration is a numbered, permanent change to the database. Running it by hand in a release step, and refusing a changed file, means the schema has one history. The release gate reads the config a deploy would use and refuses anything that could weaken the boundary, such as the test login or a missing purge cron.
