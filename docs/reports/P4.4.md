## Outcome and scope

Runs show the five labels and nothing else: Queued, Accepted, Confirmed, Failed, Simulated. Each run lists its attempts, last error code and next try. Accepted carries `uncertain: true` and help text saying nobody knows whether anyone received it. On `/admin` the owner can stop all dispatch, resume, retry a failed run, and record a Zap run reference to confirm an accepted one. All four audit.
