## Decisions and teaching notes

**Teach-back.** Business need: be ready the day an org exists. Data path: owner signs in at Salesforce, tokens are encrypted here, reads are GET only. Security boundary: database triggers keep live connections and tokens in the owner workspace. Failure: a revoked token dead-letters the run and the app keeps working. Tradeoff: Salesforce has no read-only scope, so read-only rests on this code and on a read-only user.
