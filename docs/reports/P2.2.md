## Security, quality and cost

- Cursors and filters are validated, and every value is a bind parameter. `casePageSql` builds only from fixed fragments.
- Activity returns the role that acted and never a session or user ID.
- Audit rows are private to a workspace, so shared sample cases show no history.

## Decisions and teaching notes

**Teach-back.** Every case carries a version number. Saving sends the version you loaded, and if it moved, you get a conflict and a Reload button, not a silent overwrite. Creating a case sends a one-time key, so if the reply is lost and the browser tries again, the server returns the first result and makes nothing new.
