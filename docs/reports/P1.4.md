## Decisions, teaching notes and approvals

**Teach-back.** Everything a person can press works, and everything not built says which phase adds it. Each request gets an ID that appears in the error, the response header and the log, so a screenshot leads straight to the log line. Logs have a fixed list of fields, so a cookie can't end up in one by accident.
