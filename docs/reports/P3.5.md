## Decisions and teaching notes

**Teach-back.** Business need: a consultant can see what the stock system says without being able to change it. Data path: same pipeline, exact code match, insert-only rows. Security boundary: the runtime role has no UPDATE on snapshots or items. Failure: a problem record becomes a finding and the fact stays. Tradeoff: no unit conversion, so a mismatch stays visible until a person fixes the source.
