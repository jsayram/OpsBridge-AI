## Outcome and scope

Done locally. Every dashboard number is computed per request from the transactional tables over the rows the caller already sees in the case list: a guest's workspace plus the read-only shared samples, or the owner workspace. Each metric has a written formula, a unit and one of the four PRD 11.2 provenance labels. `metric_snapshots` holds trends only; the template carries a 90-day synthetic history whose last day equals the template's live count.

The P6 brief said `metric_snapshots` existed since `0003`. It never did; `0009` creates it (D-072).

## Security, quality and cost

- Scope is enforced in SQL and again by RLS. No metric reads `outbox_attempts` or other own-only tables across workspaces.
- A metric with no source is UNKNOWN and shows "Not available", never 0.
- Cost: $0. Nine small grouped queries per overview.
