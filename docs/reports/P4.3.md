## Security, quality and cost

- Only the owner workspace can reach the bridge, and only when every value is set. A demo workspace with a sheet rule reaches the simulated sink (tested in `automation-operator.test.ts`).
- The key would be a Worker secret, the token lives in isolate memory only, and the service account would be shared on one sheet.
- Zapier Free: 100 tasks a month, and only owner events produce rows.
