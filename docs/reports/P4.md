## Phase result

Approvals now produce controlled automation effects, on a local machine. When a manager approves a case or resolves a finding, the change and its event commit together, and right after the response a dispatcher delivers the event once, retries it safely if the destination is down, and labels it with only what the evidence supports. Typed rules decide what each event does. A rule can't name a destination, and one rule serves a second fictional team without copied logic.

**What is real and what isn't.** Every demo effect is Simulated: nothing leaves the system. The owner's path into a Google Sheet, and from there a Zap, is built and tested against a labeled double that follows Google's public request shapes. No sheet, service account or Zap exists, so **P4-C is Pending Owner Credentials** under the DEC-008 standing deferral. Nothing is deployed, and Hyperdrive and Neon haven't been in any check.
