## Security, quality and cost

- Email never decides anything. `email_display` stays empty.
- No cost and no external call.

## Decisions, teaching notes and approvals

**Teach-back.** The provider signs a token and the Worker checks the signature and that the name on it is on one exact list. There is no password here to steal. Until a provider is configured, the admin area doesn't appear to exist. The test double is a throwaway key in tests, so the real checking code runs, and it won't work anywhere but a local machine.
