## Decisions and teaching notes

**Teach-back.** Business need: a failure costs a retry, not a cleanup. Data path: failure class decides retry, run state and message from one table. Security boundary: nothing from the provider reaches a person or a log. Failure: this package is the failure path. Tradeoff: a long `Retry-After` stops the run rather than holding a request open.
