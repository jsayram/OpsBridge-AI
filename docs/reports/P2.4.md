## Decisions and teaching notes

**Teach-back.** Twenty reviewers click Approve at once. Each waits for the case lock in turn. The first decides; the rest find it already decided and get a clear conflict. To prove the all-or-nothing part, a test plants a database failure at the last step, and the approval rolls back with everything else. To prove the tests can fail, a script deliberately breaks each safeguard and checks that a test notices.
