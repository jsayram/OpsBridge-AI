## Goal and business reason

A reviewer accepts, edits or rejects a suggestion, and only an accepted one can change the case, through the same version-checked checklist command a person uses. Proves P5-C, P5-D, E2E-11 and E2E-12.

**Plain language.** The suggestion is stored once and never changed. A reviewer's edits are stored beside it and pass the same checks. Accepting can apply the allowed checklist changes, but only if the case is still at the version the reviewer saw; otherwise nothing changes at all. Rejecting changes nothing on the case. Every step is in the audit log, pointing back at the review and the source segment.
