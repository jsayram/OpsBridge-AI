## Goal and business reason

Show the system can be brought back after a bad release or bad data, and that the people steps for an incident are written down and work. Proves P7-C locally, E2E-23 and E2E-24 local halves.

**Plain language.** Rollback means running the previous version again. That only works if the database changes in the new version don't break the old one, so changes are split into "add" now and "remove" a release later. Restore means rebuilding the database from a backup and checking every row came back.
