## Goal and business reason

A manager sees operations pulse, funnel, integration health, data quality, AI assistance and automation on one page, each number labeled and each chart backed by a table. Proves P6-D, P6-E and the dashboard part of JOB-21.

**Plain language.** Six dashboard sections with provenance badges, a table next to every chart, freshness and simulated-source labels, empty and unknown states, keyboard and screen-reader structure.
