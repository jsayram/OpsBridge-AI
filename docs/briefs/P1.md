# P1 — Hosted shell, identity and isolated demonstration: phase brief

Status: planned, not started. Prepared at: 2026-11-06 America/New_York by the P0 phase session. PRD: v1.3, hash in `docs/DOCUMENT-SYNC.md`. Coordinator: master thread `local_2ce00b84-dd6c-4a69-9efd-3a293bde5688`.

## Goal and business reason

One owner-approved staging HTTPS origin exists, and identity boundaries are real. A visitor launches and resets a private synthetic workspace, and nobody can reach another visitor's data or the admin area. Proves P1-A to P1-F, GOAL-02, GOAL-07, JOB-01, JOB-23.

**Plain language.** This phase turns the design into something you can open. The hard part is not the page, it's proving that two strangers in the same app can't see each other.

## Must carry forward from P0

- Spike SQL is proof, not a migration. Port it deliberately, including the D-012 function boundary.
- Every request uses an explicit transaction with `set_config(..., true)`; don't put it in a CTE.
- RLS relies on the runtime role not owning tables. Keep it that way; don't grant it ownership.
- `demo_quota`, `idempotency_keys`, `seed_demo_workspace` and the sweep jobs for Deferred findings and stuck AI reviews were not in the spike. Add and test them in the phase that uses them.
- Add a second Hyperdrive config for cleanup. Free allows 10.
- Upgrade checks recorded in `DECISIONS.md` style: TypeScript 5.9 versus 7, per Jose's rule that upgrades are advice only.
- The Neon free allowance is CU-hours. Set a 0.25 CU cap at project creation.
