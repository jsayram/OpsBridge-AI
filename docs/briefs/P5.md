## Goal and business reason

Show a useful, bounded, measurable and secure LLM workflow: a synthetic document goes in, a structured, source-linked suggestion comes out, and a person decides. Proves P5-A to P5-F, and JOB-13 in `docs/JOB-ALIGNMENT.md`.

**Plain language.** The model reads, cites and suggests. It can't write a record, call an integration or send anything. A reviewer accepts, edits or rejects, and an accepted change goes through the same version-checked command a person would use. Guests only ever see deterministic fixture output, labeled as such.

## Prerequisites

- P4 reviewed by the master and recorded in the ledger. P4-C (the real Sheet and Zap run) is Pending Owner Credentials, and DEC-008 already defers it, so it needs no new question.
- **DEC-003 is closed.** Jose's final answer on 2026-11-09 was "Stay free, fixtures only". P5 builds no hosted owner upload and no PDF parsing in the Worker. The 40 fictional documents are generated by script, their text is extracted at build time in Node, and the text ships with the seed as page-numbered segments. The app stays on Workers Free at $0.
- P5.1 therefore becomes the document lifecycle around those fixtures: attach an allowlisted fixture, read its stored segments, hash and version metadata, cleanup with the workspace. The owner upload route stays in the API only as far as the PRD security tests need it (E2E-13, the P5.1 local proof): it authorizes, checks size, declared type, magic bytes, structure and active content without parsing, and then refuses with `owner_upload_disabled`. No object is stored anywhere, so no bucket exists.
- The live AI provider (P5.3) needs an account, a key and a budget. Under DEC-008 build it against a labeled double and mark it Pending Owner Credentials. Don't create an account or key.

## Must carry forward from P4

- Migrations `0001` to `0007` are frozen. New work starts at `0008`. A changed checksum stops the runner.
- The outbox is now dispatched. A P5 command that emits an event inherits after-commit dispatch for free if its route matches `EMITTING` in `backend/src/jobs/afterCommit.ts`; add the route there. The event list is closed by the PRD: P5 must not invent an `ai.*` event type without a PRD change.
- An AI suggestion must never reach a rule, a sink or the outbox directly. Only the reviewer's ordinary command emits events.
- `opsbridge_app` has SELECT on `documents` and `ai_reviews` only (D-028). Widen grants in the migration that writes them and update the exact-grant test in `tests/integration/migrations.test.ts`.
- Any new table: RLS, write policies, composite keys, a line in `purge_demo_workspace` (now defined in `0007`), and, if seeded, a pack copy. The pack is at 38 rows of 40.
- The harness waits for `waitUntil` work, so integration tests see dispatched state. Tests must never dispatch with a non-local environment and Sheets values set: that sends a real request (D-060).
- Error handling: a class and a code, never provider text. Model output is untrusted input: strict schema, then citation check against real segment IDs, then policy.
- Long work on Workers Free: one bounded step per request or tick, durable position, no transaction across a network call.
- Local runs need Node 22 on the path. The default shell is Node 26, and CI uses 22.
